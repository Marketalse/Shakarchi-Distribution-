# Read-only pricing scenarios

Use admin-supplied or verified current unit cost, current price and target gross margin (fraction in [0,1)). Proposed net unit price = cost / (1 − target margin). Gross profit per unit = net price − cost. Margin = gross profit / net price for positive price. Markup = gross profit / cost for positive cost; not margin. For a proposed discount rate d in [0,1), net price = list price × (1 − d); target list price = cost / ((1 − target margin) × (1 − d)). Round only using approved pricing increment and recheck achieved margin. No assumed 40% target, demand elasticity or volume forecast. For scenario volume use explicitly supplied units, label hypothetical. Missing costs block recommendations. Never auto-update catalog or issued invoices. A simple on-demand calculation is sufficient for V1; a dedicated simulator UI is optional.

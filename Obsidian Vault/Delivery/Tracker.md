# GitHub tracker
Start at [repository issues](https://github.com/Marketalse/Shakarchi-Distribution-/issues). Phase issue titles carry M1–M6 so they remain queryable. [Roadmap](Roadmap.md) defines exit gates and [project management](Project-management.md) defines status and cadence.

Board specification: use an owner-scoped Project linked to this repository. Create a board grouped by Status and a table grouped by Phase. Use Status (Backlog, Ready, In progress, Review, Blocked, Done), Phase (M1–M6), Priority (P0/P1/P2) and optional target date; show Assignees and repository. Backlog is the default. Use the gate issue to link child tasks or record dependencies. Roadmap dates are historical until reforecast.
